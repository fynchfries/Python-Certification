# freeCodeCamp Python Certification

A workspace for notes, practice exercises, and the five projects in freeCodeCamp's newer Python Certification (v9).

## Layout

- `notes/` — course concepts and personal study notes.
- `exercises/` — small practice scripts grouped by topic.
- `projects/` — standalone certification-project implementations and local tests.
- `progress.md` — checklist for lessons, workshops, labs, reviews, quizzes, and projects.

The course curriculum can change. Follow the current freeCodeCamp instructions for each challenge, especially required function names, filenames, and behavior. Keep each certification project independent rather than combining them into one application.
